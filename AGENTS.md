# Installation requests

When asked to install this tool, read `.agents/skills/setup-p4-history/SKILL.md` and use its
PowerShell installer from this checkout. The default is a local source installation for GitHub
Copilot CLI. Codex and Claude Code are explicit options. A prebuilt bundle is optional.

Keep runtime installation and changelist history outside the user's Perforce workspace.
The setup skill owns the installation procedure; do not invent a separate bootstrap path.
